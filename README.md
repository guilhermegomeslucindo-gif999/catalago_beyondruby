## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel: **Add New → Project**, escolha o repositório.
3. Framework Preset: **Other**. Não precisa de Build Command nem Output Directory.
4. Clique em **Deploy**.
